# 02 / SmartStrm 安装与 115 / 夸克网盘官方双轨挂载详细步骤

本指南介绍如何在飞牛私有云（fnOS）上完成 SmartStrm 的一键安装，以及 115 网盘开放平台与夸克网盘 TV 直链驱动的配置。

---

## 一、 在飞牛私有云安装 SmartStrm

飞牛私有云（fnOS）的应用中心已官方收录 SmartStrm，安装过程极其简单：

1. 登录飞牛 NAS 桌面管理后台；
2. 打开桌面的 **应用中心**；
3. 在搜索框直接输入 `SmartStrm`；
4. 点击 **【安装】**，系统会自动在后台完成包下载、依赖解析与服务守护托管；
5. 安装完成后，在浏览器访问管理控制台：
   ```text
   http://<你的飞牛NAS_IP>:8024
   ```
6. 首次打开按提示设置管理员初始账号与密码。

### 目录持久化结构说明
- 核心配置文件：`/var/apps/smartstrm/shares/SmartStrm/config/config.yaml`
- 日志文件：`/var/apps/smartstrm/shares/SmartStrm/logs/`
- STRM 生成卷：`/var/apps/smartstrm/shares/SmartStrm/strm/<task_id>/`

## 二、 挂载 115 网盘（官方开放平台驱动 open115）

115 网盘采用官方开放平台规范，拥有长期稳定的授权与独立的 API 限速机制：

1. 浏览器打开 SmartStrm 网页端（`http://<NAS_IP>:8024`）；
2. 点击左侧导航栏 **【存储管理】** -> **【添加存储】**；
3. 参数填写：
   - **存储类型**：选择 `115开放平台 (open115)`；
   - **存储名称**：填写 `115_main`（后续配置任务必须对应）；
   - **速率限制**：填写 `1`（严格限制为 1 秒 1 次，平稳防风控）；
4. 点击 **【获取授权二维码】**，页面弹出 115 官方授权二维码；
5. 打开手机 **115 App**，点击“扫一扫”完成登录授权；
6. 授权成功后，状态显示绿色，界面会自动读出当前 VIP 等级与网盘剩余空间（如 40TB+）。

## 三、 挂载夸克网盘（TV 直链串流驱动 quark_tv）

夸克网盘必须使用 TV 直链驱动，因为只有 TV 协议支持 CDN 原画 302 直链输出：

1. 进入 SmartStrm **【存储管理】** -> **【添加存储】**；
2. 参数填写：
   - **存储类型**：选择 `夸克网盘TV (quark_tv)`；
   - **存储名称**：填写 `quark_main`；
   - **模式**：选择 `streaming`（直链串流模式）；
3. 点击 **【获取登录二维码】**，页面生成夸克登录码；
4. 打开手机 **夸克 App** 扫码授权；
5. **⚠️ 避坑提醒（设备数限制）**：
   - 夸克官方 TV 接口严格限制最多 2 台 TV 设备同时在线；
   - 如果点击获取二维码或绑定时报错 `HTTP 500 设备数超限`，按以下步骤解绑：
     1. 打开手机夸克 App -> 右下角【我的】-> 右上角【设置】->【账号与安全】->【登录设备管理】；
     2. 找到历史闲置的 TV 或第三方设备，点击 **移除/退出登录**；
     3. 重新在 SmartStrm 中扫码即可秒过。

## 四、 配置 SmartStrm 增量生成任务

在 SmartStrm 控制台 **【任务管理】** -> **【添加任务】**，分别为 115 与夸克建立标准化任务：

### 1. 115 电影任务
- **任务标识**：`115_movies`
- **存储来源**：`115_main`
- **网盘路径**：`/影音/电影`
- **生成参数配置**：
  - 勾选 `增量生成 (incremental)`：只对新增视频生成，不重复扫描；
  - 勾选 `目录时间校验 (dir_time_check)`：按修改时间快速跳过未变动文件；
  - 勾选 `保留本地资产 (keep_local_asset)`：防止误删用户手动整理的外挂字幕与海报。

### 2. 夸克 剧集任务
- **任务标识**：`quark_tv`
- **存储来源**：`quark_main`
- **网盘路径**：`/影音/剧集`
- **生成参数配置**：同上。

## 五、 QAS 容器 Webhook 联动配置（避开 127.0.0.1 大坑）

若在飞牛上安装了夸克自动转存（QAS，基于 Docker 部署），需要配置转存完成后自动通知 SmartStrm 生成直链：

> **⚠️ 核心避坑**：
> 绝不能填写 `http://127.0.0.1:8024`！因为 QAS 跑在 Docker 容器内部，`127.0.0.1` 指向的是容器自己，根本连不上宿主机。
> **正确填写**：填写 Docker 宿主网关 IP（如 `http://172.31.0.1:8024/...`）或 NAS 的局域网真实 IP（如 `http://192.168.1.100:8024/...`）。
