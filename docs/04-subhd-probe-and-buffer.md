# 04 / SubHD 免 Key 原生探针、7 天字幕缓冲队列与长周期美剧追踪

本指南详细介绍如何通过防冲动算法、字幕成熟嗅探与季播完结追踪，保障家庭影音库的观影品质。

---

## 一、 为什么设立“7 天字幕成熟防御缓冲队列”？

影视发烧友经常遭遇以下痛点：
- **Day 0 机翻陷阱**：流媒体首发上线当天，各大资源站流出的版本往往只带有平台自带的生硬机翻字幕，甚至连专有名词、角色人名都漏洞百出；
- **冲动观看毁好片**：一部好莱坞殿堂级佳作，因为糟糕的字幕彻底毁了观影心情；
- **压制组黄金周期**：国内顶级字幕组（如人人、远鉴、擦枪、弯弯等）对 4K REMUX 制作精校特效双语字幕、修复时间轴，通常需要 3 ~ 7 天时间。

### 规则设计
系统设立刚性质量门槛：
- 只要流媒体最新上线的电影 **IMDb 评分 ≥ 7.0**；
- 自动纳入 `data/buffer_queue.json` 倒计时；
- 默认锁定 7 天等待期；倒计时结束后，才触发转存入库；
- 但如果 SubHD 探针提前嗅探到了精校字幕，系统将**瞬间截断等待期，提前放行**！

---

## 二、 SubHD 字幕成熟度主动雷达嗅探 (免 Key 原生探针)

为了避免教条死等 7 天，我们实现了 SubHD 原生开放接口嗅探。

### 1. 嗅探逻辑
1. 传入影片中文标准译名，调用 SubHD 接口检索豆瓣 ID；
2. 提取该条目下的全部字幕版本池；
3. 智能加权匹配特征关键词：
   - 核心关键词：`["精校", "特效", "双语", "中英", "双字", "蓝光", "公映", "人人", "远鉴"]`；
4. 只要命中任意成熟特征，系统立即判定为：`🟢 字幕已成熟`；
5. 自动提前结束 7 天缓冲队列，当天清晨直接转存入库！

### 2. 终端实测调用
```bash
python3 scripts/fnos_watchmode_autopilot.py sub "死侍与金刚狼"
```

回显输出：
```text
=== SubHD 字幕成熟度嗅探报告 ===
片名: 《死侍与金刚狼》
成熟度判定: 🟢 字幕已成熟 (命中关键词: 精校)
```

## 三、 长周期季播美剧完结追踪器 (完结日 + 7 天黄金打包期)

### 痛点场景
追热门重磅美剧（如《权力的游戏》、《龙之家族》、《怪奇物语》）最忌讳每周等一集，前后剧情完全衔接不上；但全季播完时，人工往往容易遗忘去收全集。

### 运作规约
1. 在 `data/series_tracker.json` 挂载关注的美剧季度；
2. 系统每日巡检该季的播出排期；
3. 一旦最后一集（Season Finale）开播日期敲定，自动锁定 **[完结日 + 7 天]** 为触发节点；
4. 为什么是完结日 + 7 天？
   - 大结局播完一周内，各压制组会发布包含全季统一修正双语特效字幕的【全季 4K HDR 压制合包】；
   - 此时一键转存，既避免了零散多季目录混乱，又享受到了最成熟的字幕体验。

巡检调用：
```bash
python3 scripts/fnos_watchmode_autopilot.py series
```
