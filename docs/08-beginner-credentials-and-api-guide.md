## 一、 网盘免抓包扫码绑定指南（115 & 夸克）

### 1. 115 网盘绑定（open115 官方开放协议）
- **步骤**：
  1. 浏览器打开 SmartStrm 网页端（`http://<你的NAS_IP>:8024`）；
  2. 左侧导航进入 **【存储管理】** -> 点击 **【添加存储】**；
  3. **驱动类型**选择 `115开放平台 (open115)`，名称填 `115_main`；
  4. 速率限制填写 `1`（严格限制 1 秒 1 次，稳健防风控）；
  5. 点击 **【获取授权二维码】**；
  6. 手机打开 **115 App**，点击右上角【扫一扫】完成授权；
  7. 状态瞬间变为绿色正常，无需任何手动抓 Token 动作！

### 2. 夸克网盘绑定（quark_tv 官方 TV 串流协议）
- **步骤**：
  1. SmartStrm **【存储管理】** -> 点击 **【添加存储】**；
  2. **驱动类型**选择 `夸克网盘TV (quark_tv)`，名称填 `quark_main`；
  3. **模式**选择 `streaming`（直链原画串流模式）；
  4. 点击 **【获取登录二维码】**，手机打开 **夸克 App** 扫码授权；
  5. 授权成功即完成绑定。
- **⚠️ 避坑提醒（遇到“500 设备数超限”报错怎么办？）**：
  - 夸克官方 TV 接口限制最多同时在线 2 台设备；
  - 解决办法：打开手机夸克 App -> 右下角【我的】-> 右上角【设置】->【账号与安全】->【登录设备管理】，将旧的 TV 或网页登录记录点击**退出登录**，回到 SmartStrm 重新扫码即可秒过。

## 二、 豆瓣个人主页后缀 UID 获取方法

豆瓣想看同步功能完全免 Cookie、免登录，只需填入你的个人主页 UID：

### 方式 A：手机豆瓣 App 获取（10 秒搞定）
1. 打开手机豆瓣 App，点击右下角 **【我】**；
2. 点击顶部的**个人头像/昵称**，进入“个人主页”；
3. 点击右上角的 **【分享】** 按钮（或三个点图标）；
4. 选择 **【复制链接】**；
5. 将链接粘贴到备忘录，你会得到类似这样的链接：
   ```text
   https://www.douban.com/people/185003102/
   ```
   或者带有自定义个性域名的链接：
   ```text
   https://www.douban.com/people/myles_cinema/
   ```
6. 链接末尾 `people/` 后面的那一串字符（如 `185003102` 或 `myles_cinema`）就是你的 **DOUBAN_UID**！
7. 填入 `.env`：
   ```bash
   DOUBAN_UID="185003102"
   ```

### 方式 B：电脑网页版获取
1. 电脑浏览器打开豆瓣并登录；
2. 点击右上角你的名字 -> **【我的豆瓣】**；
3. 查看浏览器顶部的地址栏，`douban.com/people/` 后面的字符串即为 UID。

## 三、 TMDb 官方开发者 API Key 申请指南（免费秒出）

TMDb（The Movie Database）是全球最权威的影视刮削源，官方免费开放开发者 API：

1. **注册账号**：
   - 访问 [TMDb 官方注册页面](https://www.themoviedb.org/signup)；
   - 填写用户名、密码和邮箱，完成注册后前往邮箱点击激活链接。
2. **进入 API 设置**：
   - 登录 TMDb，点击右上角个人头像 -> **Settings (设置)**；
   - 在左侧菜单栏中点击 **API**（直达链接：`https://www.themoviedb.org/settings/api`）。
3. **申请密钥**：
   - 点击页面中的 **Create (创建)** 或 **Request an API Key (申请 API 密钥)**；
   - 选择 **Developer (开发者)**；
   - 勾选同意服务条款。
4. **填写应用信息（秒批，无需人工审核）**：
   - **Type of use (使用类型)**：选择 `Personal (个人)`；
   - **Application Name (应用名称)**：填写 `fnOS Home Theater`；
   - **Application URL (应用网址)**：填写 `http://localhost`；
   - **Application Summary (应用简介)**：随便填写一句（例如：`Personal NAS movie metadata scraping and home theater.`）。
5. **获取 Key**：
   - 提交表单后，页面立即秒级生成并展示你的 **API Key (v3 auth)**（一串 32 位的字母数字混合字符串）；
   - 复制该 Key 填入 `.env`：
     ```bash
     TMDB_API_KEY="你的32位TMDb_API密钥"
     ```

Watchmode 追踪 Netflix、Apple TV+、Disney+、Max 等全球流媒体的精确首发排期，免费配额足够个人家庭使用一整年：

1. **注册账号**：
   - 打开官网 [Watchmode API 注册页面](https://api.watchmode.com/)；
   - 点击右上角 **Sign Up for Free**；
   - 输入邮箱与密码完成注册。
2. **复制 API Key**：
   - 注册成功后直接进入 Dashboard（管理后台）；
   - 在页面顶部的 **Your API Key** 一栏，直接点击复制该密钥；
3. **配置参数**：
   - 填入 `.env`：
     ```bash
     WATCHMODE_API_KEY="你的Watchmode密钥"
     ```
   - *（注：如果暂时不想注册 Watchmode，不填也能正常使用豆瓣同步、SubHD 字幕成熟嗅探与全自动入库功能，核心体验完全不受影响！）*
