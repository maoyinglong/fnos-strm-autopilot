# 06 / 生产环境 5 大前线避坑铁律与排雷手册

在飞牛私有云（fnOS）搭配 SmartStrm 与 115 / 夸克网盘长期运行的过程中，我们通过数万部影视资源的实机跑通，总结了以下五大前线刚性规约与高频故障排雷手册。

---

## 一、 生产环境 5 大前线避坑铁律

### 1. 多网盘源死链顶替致死陷阱
- **故障现象**：飞牛影视海报墙将同部影片（如《星球大战：曼达洛人与古古》）聚合为一个海报，但底层同时关联了 115 与夸克双源。电视端点击播放无限转圈卡顿，报错 `HTTP 500 视频找不到`；
- **根因分析**：夸克端正片此前已被手动删除或空间清理，但 NAS 本地残留了孤儿 `.strm`；飞牛影视默认选中排在首位的夸克源，SmartStrm 返回 500，直接拦截了排在后方的 115 有效 4K 原盘直链；
- **刚性防御**：
  - 执行镜像同步时，必须严格追加 `--delete` 参数：
    ```bash
    python3 scripts/smartstrm_fnos_mirror.py --config config/fnos-mirror.json --delete
    ```
  - 同步脚本会自动比对源目录与目标目录，物理修剪已在网盘删除的孤儿死链，保障飞牛媒体库源池 100% 鲜活。

---

### 2. 网盘目录绝对扁平化原则
- **故障现象**：用户将经典大导合集（如《诺兰导演全集》或《007全系列》）建了 3~5 层嵌套子目录，结果飞牛影视完全不识别、不入库；
- **根因分析**：SmartStrm 增量扫描与 TMDB 刮削器只向上探查两级，过深的目录结构直接导致文件被丢弃或判定为无父级媒体；
- **标准规范**：
  - 电影标准结构（严格两级）：
    ```text
    /影音/电影/电影中文名 (上映年份)/电影中文名 (上映年份).mkv
    /影音/电影/电影中文名 (上映年份)/电影中文名 (上映年份).strm
    ```
  - 电视剧标准结构（严格三级）：
    ```text
    /影音/剧集/剧名/Season 01/剧名.S01E01.mkv
    /影音/剧集/剧名/Season 01/剧名.S01E01.strm
    ```

---

### 3. 飞牛图片反代服务的“两级散列硬编码”限制
- **故障现象**：数据库或元数据注入了海报路径，但在飞牛影视 Web 端或客户端浏览时，海报全裂开白板，控制台报错 `501 Not Implemented`；
- **根因分析**：飞牛影视内部的图片反代服务强制匹配路径格式为：
  ```text
  /v/api/v1/sys/img/{dir1}/{dir2}/{filename}
  ```
  如果手动注入的路径是单级目录（如 `/img/poster-123.webp`），Nginx 会直接报错拒绝转发；
- **正确规范**：手动补全海报时，必须生成两级散列路径（如 `/img/pr/oj/poster-687163.webp`）。

---

### 4. 公网网盘中性英文/拼音命名铁律 (防风控隔离)
- **场景痛点**：对于部分现实主义、历史敏感题材或存在争议的影视作品，如果在公网网盘（115 / 夸克）直接以中文名建文件夹，极易触发网盘服务端的云端敏感词哈希风控甚至整包屏蔽；
- **解耦设计**：
  - 网盘端统一采用中性英文或拼音命名（如 `Blind.Shaft.2003`、`Blind.Way.2017`）；
  - 本地飞牛影视通过 `.strm` 文件解耦承接中文海报、演职员表与简介，既保证网盘端绝对安全，又保证大屏海报墙中文视觉体验完美。

---

### 5. 上游 API SQLite 强缓存设计 (防超额与 429 限流)
- **痛点**：Watchmode、TMDb、SubHD 等上游接口存在月度免费配额上限（如 Watchmode 每月 2500 次）或频次限制；
- **解法**：在 `scripts/fnos_watchmode_autopilot.py` 中内置了 SQLite 强缓存层：
  - 电影基础详情缓存 7 天；
  - 播放源排期缓存 24 小时；
  - 字幕成熟嗅探结果缓存 24 小时；
  - 每日定时巡检的缓存命中率达到 95% 以上，彻底杜绝请求超频与账单超额扣费。

## 二、 常见故障速查 FAQ

### Q1: 夸克网盘 TV 驱动绑定时报错 `500 设备数超限` 怎么办？
**答**：夸克官方对 TV 直链接口有严格的并发设备数硬限制（最多允许 2 台 TV 设备同时登录）。
**解决步骤**：
1. 打开手机夸克 App；
2. 依次点击：右下角【我的】-> 右上角【设置】->【账号与安全】->【登录设备管理】；
3. 找到历史闲置的 TV 设备或第三方应用，点击“移除登录”；
4. 返回 SmartStrm 重新点击生成二维码扫码，即可秒级成功绑定。

---

### Q2: 夸克自动转存 (QAS) 容器的 Webhook 为什么触发不了 SmartStrm？
**答**：这是最经典的 Docker 容器网络误区！
- QAS 运行在 Docker 容器内，如果把 Webhook 地址写成 `http://127.0.0.1:8024`，请求会发给容器自己内部的端口，而 SmartStrm 运行在宿主机上，导致请求直接 Connection Refused；
- **正确写法**：必须使用容器能够访问的宿主机网关 IP（如 `http://172.31.0.1:8024`）或者飞牛 NAS 在家庭局域网内的真实 IP（如 `http://192.168.1.100:8024`）。

---

### Q3: 为什么部分非标儿童早教短片（数百上千集）无法完美刮削出海报墙？
**答**：
1. 飞牛影视对连载剧集的展示，强依赖 `TV -> Season -> Episode` 的标准命名和 TMDB 词条匹配；
2. 许多早教散装视频是网友转存的非标中文名（如 `第100集 鸽子和稻草人.mp4`），缺少标准 `S01E01` 格式，云端哈希无法命中任何影视词条；
3. **最佳工程实践**：不要在非标儿童早教短片上海报强行适配浪费精力。**推荐直接在飞牛影视中进入【文件夹视图（Directory）】浏览**，在文件夹下放置一张 `poster.jpg`，点击同样可以享受 STRM 原画秒播与连续播放体验！
